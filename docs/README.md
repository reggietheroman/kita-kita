# Privacy documentation (kita-kita)

The shared Philippine Data Privacy Act kit lives in a separate project:

**[npc-dpa-compliance](../../npc-dpa-compliance)** (`/Users/reggie/projects/npc-dpa-compliance`)

That repository is the source of truth for:
- RA 10173 / NPC research
- Privacy-by-design plan
- Notice and PIA templates
- Cursor rules and skills
- Privacy gate script and PR checklist

Copies in this app (`.cursor/`, `docs/`, `scripts/verify-privacy-gates.js`, `.github/pull_request_template.md`) are the **installed** kit so Cursor and CI still work here. When the kit changes, copy the updated files back into this repo.
